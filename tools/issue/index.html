Issue license (admin)

Mints an ECDSA-signed Duitful Pro license without going through Billplz. Useful for testing, refunds, friends & family, or promo codes. Requires your ADMIN_KEY from Vercel env vars.

Anyone with the admin key can issue unlimited keys. Rotate ADMIN_KEY in Vercel if it leaks.
Need an ADMIN_KEY? Generate one

Creates a 32-byte (64-hex-char) random string using the browser's crypto RNG. Copy it, paste into Vercel → Project → Settings → Environment Variables as ADMIN_KEY, redeploy, then paste the same value into the field below.
