License signing keypair

Generates a fresh ECDSA P-256 keypair in your browser. The private key never leaves this page — copy it once, paste it into Vercel env vars, then close the tab.

Run this exactly once. If you lose the private key you can't issue new licenses without regenerating — which would invalidate every license you've issued. Back it up safely (password manager).

Public key safe to commit

Goes into app/script.js as a constant, and also into the LICENSE_SIGNING_PUBLIC_KEY env var on Vercel. Paste the whole block, including -----BEGIN / END-----.

Private key keep secret

Goes into the LICENSE_SIGNING_PRIVATE_KEY env var on Vercel only. Never commit this, never paste it in chat, never share it. Vercel env vars are encrypted at rest.

JWK (alternative format)

Same keys in JWK format if a tool you're using prefers it. Otherwise ignore.
