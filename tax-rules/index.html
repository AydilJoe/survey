The prompt

You are helping me set up Duitful, a private budgeting app, with my country's personal income tax rules. Write them as ONE JSON object in the format below, and reply with only the JSON (no commentary, no code fence).

My country: [COUNTRY]
Tax year: [YEAR]   (the calendar year my spending happens in)
My currency: [3-LETTER CODE, e.g. SGD]

FORMAT
{
  "country": "Country name",
  "currency": "ISO 4217 code the amounts are in",
  "tax_authority": "Name of the tax office",
  "terms": {
    "authority": "short name of the tax office, e.g. IRAS",
    "year": "how a tax year is labelled, e.g. YA or Tax year",
    "withholding": "name for tax deducted from salary, e.g. PAYE",
    "pension": "name for the employee's compulsory retirement contribution, e.g. CPF",
    "filing": "name of the online filing system, e.g. myTax Portal",
    "rebate": "word for a flat tax rebate"
  },
  "tax_by_year": {
    "YEAR": {
      "bands": [ { "up_to": 20000, "rate": 0 }, { "up_to": 30000, "rate": 0.02 }, { "up_to": null, "rate": 0.24 } ],
      "rebate": { "amount": 0, "chargeable_income_up_to": 0 }
    }
  },
  "filing_by_year": {
    "YEAR": {
      "november_check": "11-15",
      "final_check": "MM-DD (a few weeks before filing opens, in YEAR+1)",
      "efiling_opens": "MM-DD (in YEAR+1)",
      "deadline": "MM-DD (filing deadline, in YEAR+1)",
      "deadline_note": "one line about the deadline",
      "keep_records_years": 5
    }
  },
  "tax_relief_categories": [
    {
      "category_id": "CAT_SOMETHING",
      "category_name": "Group name",
      "items": [
        {
          "code": "A1",
          "name": "Official name of the relief, deduction or allowance",
          "limit_YEAR": 1000,
          "sub_limits": [ { "id": "short-id", "label": "Part of the relief", "limit": 500 } ],
          "claimable_items": [ "What counts, in plain words" ],
          "eligibility_criteria": "Who can claim it",
          "required_documentation": "What to keep as proof",
          "app": {
            "id": "short-stable-id",
            "label": "Short UI name",
            "hint": "One plain line saying what counts",
            "common": true,
            "keywords": "regex source matched against spending text, e.g. \\b(gym|fitness)\\b"
          }
        }
      ]
    }
  ]
}

RULES
- Rate bands: progressive, in order, rate as a fraction (0.05 = 5%). Each "up_to" is the top of that band in chargeable income; the last band has "up_to": null.
- Every item needs a unique "code" and a "limit_YEAR" key (use the real year, e.g. "limit_2026"). A number is the yearly cap; null means it doesn't exist that year.
- Sub-limits sit inside their item's cap. Use null for "sub_limits" when there are none.
- Reliefs everyone gets automatically (personal allowance, spouse, children) get "app": { "auto": "<kind>" }, where kind is one of: individual, spouse, disabledSelf, disabledSpouse, child, childPre, childTertiary, disabledChild. Leave out "keywords" for those.
- For the employee's compulsory pension contribution relief, add "employeeEpf": true to its "app" block.
- Give "keywords" to reliefs ordinary spending can match (medical, education, sports, books, insurance, childcare, donations…), in the languages people in my country write receipts in. Use \\b word boundaries; escape backslashes for JSON.
- Only include reliefs for resident individuals. Use the official figures for the year I gave; if you aren't sure of a figure, leave that relief out instead of guessing.
- Dates are "MM-DD". If my country has no flat rebate, use { "amount": 0, "chargeable_income_up_to": 0 }.
- Add "zakat_rebate": true only if religious-tax payments come off income tax one-for-one in my country.

After the JSON, I will check every figure against the tax office's own website.

Private by design

  • Your rules are saved inside your encrypted data on your phone, like everything else in Duitful. Nothing is uploaded.
  • They replace Malaysia's rules while they're there. Back to Malaysia's on the same card removes them.
  • Everything Duitful shows is an estimate for planning, not tax advice.

The format

The same format as Duitful's own Malaysian schedule, which is the fullest example. Keys ending in _myr there have plain twins: limit_2026 for limit_ya_2026_myr, limit for limit_myr, tax_by_year and filing_by_year.

KeyWhat it is
countryCountry name, shown on the Tax page.
currencyRequired. The 3-letter code the amounts are in (SGD, GBP, EUR). Tax switches on when this matches the currency you keep your money in.
termsYour country's words: authority, year, withholding (tax taken from pay), pension, filing, rebate. Anything left out gets a plain word.
tax_by_yearRate bands and any flat rebate, per year. A year without its own entry uses the nearest earlier one.
filing_by_yearOptional. The check-in dates and the filing deadline, as "MM-DD".
tax_relief_categoriesGroups of reliefs. Each item needs a unique code, a name and a limit_<year>.
app.autoReliefs given without a receipt: individual, spouse, disabledSelf, disabledSpouse, child, childPre, childTertiary, disabledChild.
app.keywordsA regular expression. Spending whose category or note matches is offered as a claim for this relief.
zakat_rebateOptional. true if zakat paid comes off income tax one-for-one.
